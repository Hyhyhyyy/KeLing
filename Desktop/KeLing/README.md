## ✨ 核心功能

| 特性 | 说明 |
|------|------|
| 📱 **Android 移动端** | Kotlin + Jetpack Compose + Material Design 3 + MVVM |
| 🌐 **Web 网页端** | React 18 + TypeScript + Vite + Zustand + Framer Motion |
